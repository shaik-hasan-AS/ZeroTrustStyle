Wireshark Packet Analysis Guide
Step-by-step instructions to inspect mTLS handshakes and encrypted data on the wire.
sudo wireshark -i any -k -f "tcp port 8000 or tcp port 8001 or tcp port 8002"
tls.handshake.type == 13 Cert Request
tls.handshake.type == 11 Certificates
tls.handshake.type == 15 Cert Verify
tcp.port in {8000, 8001, 8002} Mesh Ports
What to show the audience:
  1. Certificate Request (Type 13): Show that the server sends a Certificate Request. In regular one-way HTTPS, servers never ask for client certs.
  2. Client Certificate Exchange (Type 11): Show the client replying with its certificate (Subject CN client-fintech-portal or account-service).
  3. Encrypted Traffic: Show that all transfer amounts and JSON payloads are completely encrypted under TLS 1.3 / AES-256.
  4. Layer 7 Policy Defense (Scenario 8): Show that even when a rogue cert completes TLS at Layer 4, OPA rejects the request with HTTP 403 at Layer 7.
